Access Level Hierarchy (RBAC)

Format: primary-sub — e.g. superuser-manager

Superuser superuser-manager / superuser-regular
Full unrestricted access. Bypasses all permission checks. System configuration, all admin features.
Admin admin-manager / admin-regular
Create users, change access levels, view login history, manage team, approve tools.
Manager (sub-level) user-manager
Create automations, manage department, access API Hub, Tool Builder. All regular user features.
Regular (sub-level) user-regular
Standard access. Documents, templates, cloud storage, AI assistant, team view.

Getting Started

Welcome to Horison AIOS! This version is powered by Supabase cloud.

  • Your data is stored in a real Supabase Postgres database
  • Authentication is handled by Supabase Auth (email/password)
  • Files are stored in Supabase Storage buckets
  • All data syncs across devices and team members
Cloud Storage
Upload files via the Cloud Storage page. Files are stored in Supabase Storage and accessible from anywhere.
Team Collaboration
All team members share the same database. Documents, templates, and files are visible to everyone based on their role.
